1. 备份 settings 恢复语义
- 数据库层新增显式 settingsAction（keep/set/reset），取代无条件清空 settings
- merge + 无有效设置 -> keep：保留当前设置（此前被错误清空）
- replace + 无有效设置 -> reset：回落 DEFAULT_SETTINGS
- 备份含有效设置 -> set
- React 状态写入后从数据库回读，UI 与数据库不再可能不一致
- 新增导入后刷新页面的持久化测试（单元 + 真实浏览器）

2. 跨题库恢复安全
- 修复 needsAck 无法解除的确认死锁：改为可验证内容正常导入、无法验证内容排除并说明原因
- 新增 filterPayloadToBank()：题目 ID 由内容生成，「ID 可匹配」即题目—选项—答案绑定证明
- 学习记录/历史/AI 评阅仅保留可匹配条目；模拟考试仅当全部题目可匹配才导入
- 页面展示「备份中 / 可验证」计数与逐类排除数量；非空备份若无任何可验证条目，
  说明「没有可导入的内容」并禁用确认（原因可见，非死锁）
- 旧版无指纹备份保留受控恢复，仍逐题按 ID 匹配并展示风险
- 新增真实 UI 测试：已勾选确认、存在不匹配记录、旧版备份、取消恢复、刷新后一致性

3. 统一作答身份（AI 评阅不再重复计训练次数）
- 统一为 attemptIdFor(sessionId, qid)，练习/主观训练/模拟考试/AI 评阅共用同一规则
- 新增 hasAttempt() 按 (qid, sessionId) 扫描，可识别旧版随机 ID 历史行；
  不删除、不重算用户原有记录，仅不再叠加新的一次
- 新增 recordAttempt() 按 (sessionId, qid) 幂等
- 模拟考试传给 AI 面板的 sessionId 统一为 runId（原 mock-${runId} 与交卷写入不一致）
- 新增真实路径测试 A-D：主观题提交→评阅=1；反复评阅=1；模拟考试→评阅=1；
  评阅保存失败原作答与统计不变；另有旧版随机 ID 行兼容测试

4. AI 代理远程安全边界
- 移除 AI_ALLOW_REMOTE 开关：非回环 AI_HOST 一律拒绝启动
- 新增逐请求回环校验，非回环来源 403，覆盖 qa/grade 等所有消耗额度接口
- 文档与启动日志说明改用 SSH 隧道或带认证反向代理
- 保留密钥不回显、异常响应校验、错误降级
