# 复习策略

本文说明 ExamPilot 采用的复习算法、其学习科学依据、可调参数与已知限制。

## 设计目标

以提高真实考试表现为最高优先级，具体落到四个可度量目标：

1. **覆盖率** — 题库中实际练过的题目比例
2. **正确率** — 已练题目中的答对比例
3. **错题清除** — 答错的题目被复刷到连续答对
4. **结构能力** — 主观题能按采分点组织作答

## 采用的五种方法

### 1. 主动回忆（Active Recall）

先作答、后看解析。`QuestionRunner` 在所有模式下都要求提交答案才揭示结果，主观题要求完整书写而非列要点。

依据：提取练习效应（testing effect）——主动生成答案比重复阅读更能强化长期保持。

### 2. 间隔复习（Spaced Repetition）

答对后复习间隔按 `1 → 2 → 4 → …` 天递增（`interval * ease`，`ease = 2.0`），答错立即重置为最短间隔。下次复习时间存入 `records.nextReviewAt`。

依据：间隔效应（spacing effect）——分散练习优于集中练习。

### 3. 错题再测（Error-driven Review）

答错的题目权重提高，连续错误（`wrongCount >= 3`）标记为 `struggling`；错题本只收录真实答错过的题，并按答错次数排序。

依据：从错误中学习；对未掌握内容的针对性练习效率最高。

### 4. 混合练习（Interleaving）

选题不按知识块连续出题：章节与题型在权重抽样中混合，避免短期重复同一内容造成的「熟练错觉」。

依据：交错练习（interleaving）提升辨析与迁移能力。

### 5. 覆盖均衡（Coverage Balancing）

这是本项目最重要的约束。选题权重中：

- 从未练过的题目权重 ×2（`attempts === 0`）
- 已掌握题目权重 ×0.15
- 到期复习 +6，错题/难点 +4，学习中 +2

因此复习计划始终包含未做题目，**不会退化成只刷错题**。

依据：覆盖不足是失分的主因之一；只练错题会让大量题目从未被检验。

## 状态机

```
new ──答对1次──▶ learning ──连续答对且间隔≥3天──▶ mastered
 ▲                  │
 └────答错3次──── struggling ◀──答错────┘
```

`status` 由 `applyAttempt()` 依据真实尝试次数与错误次数推导，永不由 UI 直接设置，也不因「未作答」而变化。

## 掌握判定

- **单选题**：所选字母与 `answerNorm` 完全一致
- **多选题**：选项集合与答案集合**完全一致**——错选、漏选、多选均判错
- **判断题**：布尔值与 `answerNorm` 一致
- **主观题**：不自动评分，仅记录「已训练」；AI 评阅单独存档并标注为参考评阅

未作答：`scoreAnswer` 返回 `null`，不计入正确或错误，也不标记为已练。

## 可调参数

| 参数 | 位置 | 默认 | 说明 |
| --- | --- | --- | --- |
| `ease` | `scheduler.ts` `DEFAULT_EASE` | 2.0 | 间隔增长倍率 |
| 各权重 | `scheduler.ts` `weight()` | 见上 | 选题偏好 |
| 每日目标题量 | 设置页 | 30 | 仅作展示目标 |
| 复习间隔基数 | 设置页 | 1 | 叠加到 `ease` |

## 模拟考试

题型、题量、分值、时长、章节范围全部可配置。**未获知正式考试要求时，默认值只是模板，不代表真实考纲。**

交卷后成绩与练习共用同一套记录写入，因此模拟考试既是检验也是训练。

## 诊断指标

| 指标 | 计算方式 |
| --- | --- |
| 覆盖率 | 已练客观题数 / 客观题总数 |
| 正确率 | 答对次数 / 总作答次数（仅客观题） |
| 掌握指数 | 覆盖率 × 0.4 + 正确率 × 0.6 |
| 薄弱点 | 掌握指数升序取前 6 |

所有指标由真实作答汇总得出。**系统不生成预测成绩，不虚构掌握率。**

## 限制

1. **`ease` 固定**：未实现根据题目难度动态调整的 SM-2 变体；当前实现刻意保持简单可预测。
2. **间隔上限 365 天**：对一学期复习周期足够，但未做长周期验证。
3. **无遗忘曲线建模**：不使用历史遗忘率拟合个体记忆参数。
4. **主观题无自动评分**：题库不提供标准答案，系统拒绝伪造；只能依赖 AI 参考评阅或人工自评。
5. **诊断基于频次而非认知诊断**：未做知识点级（knowledge tracing）建模，章节粒度是最细诊断单位。
6. **单一用户**：无多人数据隔离或云端同步。
